# local-rust-server

Pocket MCR (Android) için Rust tabanlı Minecraft Java sunucu motorunun derlenmiş sürümleri.

Bu motor **Horizon**'dur, Starling ekibinin çalışmasıdır, MIT lisanslıdır.
Asıl proje: https://github.com/starling-client/starling

Bu depo Horizon'un bir kopyasıdır (fork). Burada yalnızca Android (arm64, musl) için derleme
iş akışları ve sürüm dosyaları bulunur. Kaynak kod, telif ve lisans notları (`LICENSE`,
`THIRD_PARTY_NOTICES.md`) değiştirilmeden korunur. Bu depo Horizon yazarlarıyla bağlantılı değildir.

Minecraft, Mojang Studios ve Microsoft'un markasıdır. Bu depoda Minecraft oyun dosyası yoktur.
